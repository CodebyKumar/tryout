How one interview runs

  1. Describe the role

    Paste a job description or start from a template. The AI drafts the interview plan, with timed parts and what to find out in each, and a weighted scoring rubric. You can edit both.

  2. Invite candidates

    Each candidate gets a private link, open any time or within a window you set. Invite opens a ready-to-send message in your Gmail, with a calendar file for scheduled interviews.

  3. The candidate talks with the interviewer

    A voice conversation in the browser, as long as the role sets. It asks about their resume, follows up when an answer is vague, and keeps each part to its time. Typing works too.

  4. You read the report and decide

    Each criterion has a rating, a score out of 10 and the quotes behind it, linked to the transcript. The AI suggests advance, hold or reject. The decision is yours.

The AI proposes. Code decides.

The language model writes the questions and reads the answers. The rules that make every candidate's interview comparable are ordinary code, and each turn records which was which.

The model
Drafts the plan from the job description, reads the resume for claims worth checking, writes each follow-up, and rates each criterion with quotes.
The code
Decides when to move to the next part, how many follow-ups a topic gets and how much time is left. Checks that each quote really is in the transcript, computes the weighted score and the suggestion, and replaces any reply that tells the candidate whether they were right.
The record
The report's "How it decided" tab shows, for every answer, what the model proposed, what the code kept or overrode, and how long it took.

Integrity checks, stated plainly

The interview room notes what a browser can see and shows it on the report. These signals are context for a person. They are never part of the score.

Noted
Leaving the tab or window, leaving full screen, copying and pasting, a second screen, and browser extensions that write into the page.
Strict mode
A per-role setting: full screen to start, a pause whenever the candidate leaves it, copy, paste and right-click turned off, and no start while a detectable extension is on.
Not possible
A web page cannot list every extension, switch them off, or see a phone on the desk. The lobby and the report say so.
